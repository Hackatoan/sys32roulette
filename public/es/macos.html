// GUÍA DE CONFIGURACIÓN DE MACOS

Ejecución de la aplicación en macOS

La aplicación no está firmada con un certificado de Apple Developer, por lo que macOS la bloqueará en el primer inicio. Así es como puedes abrirla y hacer que todo funcione.

// PASO 1 — OBLIGATORIO

Omisión de Gatekeeper

⚠ POR QUÉ SUCEDE ESTO
La aplicación se distribuye directamente (no a través de la Mac App Store) y no está notarizada con un certificado de Apple Developer. macOS bloquea las aplicaciones no firmadas por defecto para proteger a los usuarios. La aplicación carga sys32.hackatoa.com en una ventana y, si pierdes, hace exactamente lo que dice que hace.
1
Descargar e instalar el DMG
Descarga el .dmg de GitHub Releases. Open it, drag System 32 Roulette to your Applications folder.
2
Try to open — macOS will block it
Double-clicking the app shows: "System 32 Roulette cannot be opened because it is from an unidentified developer." Click OK to dismiss.
3
Open System Settings → Privacy & Security
Go to Menú Apple → Configuración del Sistema → Privacidad y seguridad. Desplázate hacia abajo hasta la sección de seguridad. Verás:

System 32 Roulette se bloqueó porque no proviene de un desarrollador identificado. Abrir de todos modos
Haz clic en Abrir de todos modos.
4
Confirma en el cuadro de diálogo
macOS muestra un cuadro de diálogo de confirmación final. Haz clic en Abrir. La aplicación se abre. Solo necesitas hacer esto una vez; los lanzamientos futuros funcionarán con normalidad.
Alternativa (más rápida): Haz clic derecho en la aplicación en Aplicaciones → Abrir → Abrir en el diálogo. Omite la configuración del sistema por completo.
// PASO 2 — OPCIONAL

Habilitar atajos de teclado (F11 Pantalla completa)

✓ EL JUEGO FUNCIONA SIN ESTO
Esto solo afecta al conmutador de pantalla completa F11 y a la tecla Escape para salir de la pantalla completa. Si no los usas, omite este paso.

Los atajos de teclado globales requieren acceso de Accesibilidad en macOS. Cuando presiones por primera vez F11 la aplicación te lo pedirá automáticamente, o sigue estos pasos manualmente:

1
Abrir Privacidad y seguridad → Accesibilidad
Go to Menú Apple → Configuración del Sistema → Privacidad y seguridad → Accesibilidad.
2
Activa System 32 Roulette
Busca System 32 Roulette en la lista y actívalo.

Terminal
System 32 Roulette
Si aún no aparece en la lista, inicia la aplicación y presiona F11 una vez; aparecerá.
3
Reiniciar la aplicación
Sal y vuelve a abrir System 32 Roulette. F11 ahora cambia a pantalla completa y Escape sale de ella.
// Preguntas frecuentes

Preguntas frecuentes

¿La aplicación es realmente segura?
El juego hace lo que dice. Si pierdes, la aplicación intenta eliminar tu sistema; en macOS solicita tu contraseña de administrador mediante un cuadro de diálogo del sistema y luego borra el volumen de datos (/Users, /Applications, /Library, /usr/local). SIP protege los archivos principales del sistema operativo, pero todo lo demás es juego limpio. Instálalo solo si hablas en serio. El código fuente está en GitHub.
No veo "Abrir de todos modos" en Configuración del Sistema
Debes intentar abrir la aplicación primero (paso 2): el botón "Abrir de todos modos" solo aparece después de que macOS haya bloqueado una aplicación específica. Intenta hacer doble clic en la aplicación en Aplicaciones, cierra el cuadro de diálogo de error y luego verifica Configuración del Sistema → Privacidad y seguridad de inmediato.
¿Puedo jugar en el navegador en su lugar?
Sí — sys32.hackatoa.com/play funciona en cualquier navegador moderno. La aplicación de escritorio solo añade una ventana nativa y atajos de pantalla completa.
¿Qué Mac necesito: Intel o Apple Silicon?
La descarga es un binario universal: se ejecuta de forma nativa tanto en Macs con Intel (x86_64) como con Apple Silicon (M1/M2/M3/M4) sin Rosetta.
