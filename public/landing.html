// THE MINIGAMES

Three Ways to Lose

⌨
MINIGAME 1
Command Injection
Both players must type the same destructive command — exactly, character for character. First to finish wins. One wrong key and you're restarting.
🖱
MINIGAME 2
Buffer Overflow
Targets flash across a grid. Click as many as possible in 12 seconds. Pure reflexes. Whoever clicks more "overflows the buffer" first.
🧠
MINIGAME 3
Memory Dump
A pattern of cells lights up for 3.5 seconds. Memorize it. When it goes dark, reconstruct it. Highest accuracy wins the round.
