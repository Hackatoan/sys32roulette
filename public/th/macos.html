// คู่มือการติดตั้ง MACOS

การรันแอปบน macOS

แอปนี้ไม่ได้ลงนามด้วยใบรับรอง Apple Developer ดังนั้น macOS จะบล็อกการเปิดใช้งานครั้งแรก วิธีเปิดและตั้งค่าให้ใช้งานได้มีดังนี้

// ขั้นตอนที่ 1 — จำเป็น

การข้าม Gatekeeper

⚠ ทำไมถึงเกิดสิ่งนี้ขึ้น
แอปนี้เผยแพร่โดยตรง (ไม่ได้ผ่าน Mac App Store) และไม่ได้รับการรับรองด้วยใบรับรอง Apple Developer โดยค่าเริ่มต้นแล้ว macOS จะบล็อกแอปที่ไม่ได้ลงนามเพื่อความปลอดภัยของผู้ใช้ แอปนี้จะโหลด sys32.hackatoa.com ในหน้าต่าง — และถ้าคุณแพ้ มันจะทำอย่างที่บอกไว้
1
ดาวน์โหลดและติดตั้ง DMG
ดาวน์โหลด .dmg จาก GitHub Releases. Open it, drag System 32 Roulette ไปยังโฟลเดอร์ Applications ของคุณ
2
Try to open — macOS will block it
Double-clicking the app shows: "System 32 Roulette cannot be opened because it is from an unidentified developer." คลิก OK เพื่อปิด
3
Open System Settings → Privacy & Security
Go to เมนู Apple → การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย & Security. เลื่อนลงไปที่ส่วนความปลอดภัย คุณจะเห็น:

System 32 Roulette ถูกบล็อกไม่ให้ใช้งานเนื่องจากไม่ได้มาจากนักพัฒนาที่ระบุตัวตนได้ เปิดต่อไป
คลิก เปิดต่อไป.
4
ยืนยันในกล่องโต้ตอบ
macOS จะแสดงกล่องโต้ตอบยืนยันครั้งสุดท้าย คลิก เปิด. แอปจะเปิดขึ้น คุณจะต้องทำขั้นตอนนี้เพียงครั้งเดียว — การเปิดใช้งานครั้งต่อๆ ไปจะทำงานตามปกติ
ทางเลือก (เร็วกว่า): คลิกขวาที่แอปใน Applications → เปิด → เปิด ในกล่องโต้ตอบ ข้าม System Settings ไปเลย
// ขั้นตอนที่ 2 — ไม่บังคับ

เปิดใช้งานทางลัดแป้นพิมพ์ (F11 เต็มจอ)

✓ เกมใช้งานได้โดยไม่ต้องทำขั้นตอนนี้
ผลลัพธ์นี้จะมีผลเฉพาะกับปุ่มสลับโหมด F11 เต็มจอและปุ่ม Escape สำหรับออกจากการแสดงผลเต็มจอเท่านั้น หากคุณไม่ได้ใช้งานปุ่มเหล่านี้ ข้ามขั้นตอนนี้ไปได้เลย

ทางลัดแป้นพิมพ์ส่วนกลางจำเป็นต้องมีการเข้าถึงการช่วยสำหรับการเข้าถึง (Accessibility) บน macOS เมื่อคุณกดครั้งแรก F11 แอปจะแจ้งเตือนคุณโดยอัตโนมัติ — หรือทำตามขั้นตอนเหล่านี้ด้วยตนเอง:

1
เปิด ความปลอดภัยและความเป็นส่วนตัว → การช่วยการเข้าถึง
Go to เมนู Apple → การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย & Security → การช่วยการเข้าถึง.
2
เปิดสวิตช์ System 32 Roulette
ค้นหา System 32 Roulette ในรายการแล้วเปิดสวิตช์

Terminal
System 32 Roulette
หากยังไม่อยู่ในรายการ ให้เปิดแอปขึ้นมาแล้วกด F11 หนึ่งครั้ง — รายการจะปรากฏขึ้น
3
รีสตาร์ทแอป
ปิดแล้วเปิด System 32 Roulette ใหม่ F11 ตอนนี้ใช้สลับโหมดเต็มจอ, Escape ออกจากโหมดเต็มจอ
// คำถามที่พบบ่อย

คำถามที่พบบ่อย

แอปนี้ปลอดภัยจริงไหม?
เกมนี้ทำตามที่บอกไว้ ถ้าคุณแพ้ แอปจะพยายามลบระบบของคุณ — บน macOS จะมีการขอรหัสผ่านผู้ดูแลระบบผ่านหน้าต่างระบบ จากนั้นจะล้างข้อมูลในโวลุ่ม Data ออกทั้งหมด (/Users, /Applications, /Library, /usr/local) SIP จะปกป้องไฟล์ระบบหลัก แต่นอกเหนือจากนั้นถือว่าโดนลบหมด ติดตั้งก็ต่อเมื่อคุณแน่ใจเท่านั้น ซอร์สโค้ดอยู่บน GitHub.
ฉันไม่เห็นปุ่ม "Open Anyway" ใน System Settings
คุณต้องลองเปิดแอปก่อน (ขั้นตอนที่ 2) — ปุ่ม "Open Anyway" จะปรากฏขึ้นก็ต่อเมื่อ macOSบล็อกแอปนั้นๆ ไปแล้ว ลองดับเบิลคลิกที่แอปในโฟลเดอร์ Applications ปิดหน้าต่างข้อผิดพลาด แล้วตรวจสอบที่ System Settings → Privacy & Security ทันที
ฉันเล่นบนเบราว์เซอร์แทนได้ไหม?
ได้ — sys32.hackatoa.com/play ใช้ได้กับเบราว์เซอร์สมัยใหม่ทุกตัว เวอร์ชันเดสก์ท็อปแค่เพิ่มหน้าต่างเนทีฟและทางลัดสำหรับโหมดเต็มจอ
ฉันต้องใช้ Mac รุ่นไหน — Intel หรือ Apple Silicon?
การดาวน์โหลดเป็นแบบยูนิเวอร์แซลไบนารี — สามารถเล่นได้ทันทีทั้งบน Mac ชิป Intel (x86_64) และ Apple Silicon (M1/M2/M3/M4) โดยไม่ต้องใช้ Rosetta
