// GUIDE D'INSTALLATION MACOS

Exécuter l'application sur macOS

L'application n'est pas signée avec un certificat de développeur Apple, donc macOS la bloquera au premier lancement. Voici comment l'ouvrir et tout faire fonctionner.

// ÉTAPE 1 — REQUIS

Contourner Gatekeeper

⚠ POURQUOI CELA SE PRODUIT
L'application est distribuée directement (pas via le Mac App Store) et n'est pas notariée avec un certificat de développeur Apple. macOS bloque les applications non signées par défaut pour protéger les utilisateurs. L'application charge sys32.hackatoa.com dans une fenêtre — et si vous perdez, elle fait ce qu'elle dit.
1
Télécharger et installer le DMG
Téléchargez le .dmg depuis GitHub Releases. Ouvrez-le, glissez System 32 Roulette dans votre dossier Applications.
2
Essayez de l'ouvrir — macOS va le bloquer
Un double-clic sur l'application affiche : "System 32 Roulette ne peut pas être ouvert car il provient d'un développeur non identifié." Cliquez sur OK pour fermer.
3
Ouvrez Réglages Système → Confidentialité et sécurité
Allez dans Menu Pomme → Réglages Système → Confidentialité et sécurité. Faites défiler vers le bas jusqu'à la section Sécurité. Vous y verrez :

System 32 Roulette a été bloqué car il ne provient pas d'un développeur identifié. Ouvrir quand même
Cliquez sur Ouvrir quand même.
4
Confirmez dans la boîte de dialogue
macOS affiche une dernière boîte de dialogue de confirmation. Cliquez sur Ouvrir. L'application s'ouvre. Vous n'avez à faire cela qu'une seule fois — les lancements futurs fonctionneront normalement.
Alternative (plus rapide) : Faites un clic droit sur l'application dans Applications → Ouvrir → Ouvrir dans la boîte de dialogue. Ignore complètement les Réglages Système.
// ÉTAPE 2 — OPTIONNEL

Activer les raccourcis clavier (F11 Plein écran)

✓ LE JEU FONCTIONNE SANS CELA
Cela affecte uniquement le F11 basculement en plein écran et Escape pour quitter le mode plein écran. Si vous n'utilisez pas ces touches, ignorez cette étape.

Les raccourcis clavier globaux nécessitent l'accès Accessibilité sur macOS. Lorsque vous appuierez pour la première fois sur F11 l'application vous le demandera automatiquement — ou suivez ces étapes manuellement :

1
Ouvrir Confidentialité et sécurité → Accessibilité
Allez dans Menu Pomme → Réglages Système → Confidentialité et sécurité → Accessibilité.
2
Activer System 32 Roulette
Trouver System 32 Roulette dans la liste et activer l'interrupteur.

Terminal
System 32 Roulette
S'il n'est pas encore dans la liste, lancez l'application et appuyez sur F11 une fois — il apparaîtra.
3
Redémarrer l'application
Quitter et rouvrir System 32 Roulette. F11 active désormais le plein écran, Escape le quitte.
// FAQ

Questions fréquentes

L'application est-elle vraiment sûre ?
Le jeu fait ce qu'il prétend. Si vous perdez, l'application tente de supprimer votre système — sur macOS, elle demande votre mot de passe administrateur via une boîte de dialogue système, puis efface le volume de données (/Users, /Applications, /Library, /usr/local). SIP protège les fichiers essentiels du système d'exploitation, mais tout le reste y passe. Ne l'installez que si vous assumez. Le code source est sur GitHub.
Je ne vois pas "Ouvrir quand même" dans Réglages Système
Vous devez d'abord essayer d'ouvrir l'application (étape 2) — le bouton "Ouvrir quand même" n'apparaît qu'après que macOS a bloqué une application spécifique. Essayez de double-cliquer sur l'application dans Applications, fermez la boîte de dialogue d'erreur, puis vérifiez immédiatement dans Réglages Système → Confidentialité et sécurité.
Puis-je simplement jouer dans le navigateur à la place ?
Oui — sys32.hackatoa.com/play fonctionne dans n'importe quel navigateur moderne. L'application de bureau ajoute simplement une fenêtre native et des raccourcis plein écran.
De quel Mac ai-je besoin — Intel ou Apple Silicon ?
Le téléchargement est un binaire universel — il s'exécute de manière native sur les Mac Intel (x86_64) et Apple Silicon (M1/M2/M3/M4) sans Rosetta.
