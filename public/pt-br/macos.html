// MACOS SETUP GUIDE

Executando o aplicativo no macOS

O aplicativo não está assinado com um certificado de Desenvolvedor da Apple, então o macOS irá bloqueá-lo na primeira execução. Veja como abri-lo e fazer tudo funcionar.

// STEP 1 — REQUIRED

Contornando o Gatekeeper

⚠ WHY THIS HAPPENS
O aplicativo é distribuído diretamente (não pela Mac App Store) e não possui notarização com um certificado de Desenvolvedor da Apple. O macOS bloqueia aplicativos não assinados por padrão para proteger os usuários. O aplicativo carrega sys32.hackatoa.com em uma janela — e se você perder, ele faz o que diz que faz.
1
Baixar e instalar o DMG
Baixe o .dmg de GitHub Releases. Open it, drag System 32 Roulette para a sua pasta Applications.
2
Try to open — macOS will block it
Double-clicking the app shows: "System 32 Roulette cannot be opened because it is from an unidentified developer." Click OK to dismiss.
3
Open System Settings → Privacy & Security
Go to Menu Apple → Ajustes do Sistema → Privacidade e Segurança. Role para baixo até a seção de Segurança. Você verá:

O System 32 Roulette foi bloqueado porque não é de um desenvolvedor identificado. Abrir Assim Mesmo
Clique em Abrir Assim Mesmo.
4
Confirme na janela de diálogo
O macOS exibe uma janela de confirmação final. Clique em Abrir. O aplicativo é aberto. Você só precisa fazer isso uma vez — os lançamentos futuros funcionarão normalmente.
Alternativa (mais rápida): Clique com o botão direito no app em Aplicativos → Abrir → Abrir na caixa de diálogo. Pula os Ajustes do Sistema completamente.
// PASSO 2 — OPCIONAL

Ativar Atalhos de Teclado (F11 Tela Cheia)

✓ O JOGO FUNCIONA SEM ISSO
Isso afeta apenas o atalho de F11 para tela cheia e a tecla Escape para sair da tela cheia. Se você não usa esses recursos, pule esta etapa.

Os atalhos de teclado globais exigem acesso à Acessibilidade no macOS. Quando você pressionar pela primeira vez F11 o app solicitará automaticamente — ou siga estes passos manualmente:

1
Abra Privacidade & Segurança → Acessibilidade
Go to Menu Apple → Ajustes do Sistema → Privacidade e Segurança → Acessibilidade.
2
Ative o System 32 Roulette
Encontre System 32 Roulette na lista e ative a chave.

Terminal
System 32 Roulette
Se ele ainda não estiver na lista, abra o aplicativo e pressione F11 uma vez — ele aparecerá.
3
Reiniciar o aplicativo
Feche e abra novamente o System 32 Roulette. F11 agora alterna para tela cheia, Escape sai dela.
// FAQ

Perguntas Frequentes

O aplicativo é realmente seguro?
O jogo faz o que promete. Se você perder, o aplicativo tenta excluir seu sistema — no macOS, ele solicita sua senha de administrador por meio de uma caixa de diálogo do sistema e, em seguida, apaga o volume de Dados (/Users, /Applications, /Library, /usr/local). O SIP protege os arquivos principais do sistema operacional, mas todo o resto está sujeito a exclusão. Só instale se tiver certeza. O código-fonte está no GitHub.
Não vejo "Abrir assim mesmo" nas Configurações do Sistema
Você precisa tentar abrir o aplicativo primeiro (etapa 2) — o botão "Abrir assim mesmo" só aparece depois que o macOS bloqueia um aplicativo específico. Tente clicar duas vezes no aplicativo em Aplicativos, feche a caixa de diálogo de erro e verifique imediatamente Configurações do Sistema → Privacidade e Segurança.
Posso apenas jogar no navegador?
Sim — sys32.hackatoa.com/play funciona em qualquer navegador moderno. O aplicativo para desktop apenas adiciona uma janela nativa e atalhos de tela cheia.
Qual Mac eu preciso — Intel ou Apple Silicon?
O download é um binário universal — ele roda nativamente tanto em Macs com Intel (x86_64) quanto Apple Silicon (M1/M2/M3/M4) sem precisar do Rosetta.
