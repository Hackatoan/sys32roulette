// MACOS SETUP GUIDE

Running the App on macOS

The app is not signed with an Apple Developer certificate, so macOS will block it on first launch. Here's how to open it and get everything working.

// STEP 1 — REQUIRED

Bypassing Gatekeeper

⚠ WHY THIS HAPPENS
The app is distributed directly (not through the Mac App Store) and is not notarized with an Apple Developer certificate. macOS blocks unsigned apps by default to protect users. The app loads sys32.hackatoa.com in a window — and if you lose, it does what it says it does.
1
Download and install the DMG
Download the .dmg from GitHub Releases. Open it, drag System 32 Roulette to your Applications folder.
2
Try to open — macOS will block it
Double-clicking the app shows: "System 32 Roulette cannot be opened because it is from an unidentified developer." Click OK to dismiss.
3
Open System Settings → Privacy & Security
Go to Apple menu → System Settings → Privacy & Security. Scroll down to the Security section. You'll see:

System 32 Roulette was blocked from use because it is not from an identified developer. Open Anyway
Click Open Anyway.
4
Confirm in the dialog
macOS shows a final confirmation dialog. Click Open. The app opens. You only need to do this once — future launches work normally.
Alternative (faster): Right-click the app in Applications → Open → Open in the dialog. Skips System Settings entirely.
// STEP 2 — OPTIONAL

Enable Keyboard Shortcuts (F11 Fullscreen)

✓ THE GAME WORKS WITHOUT THIS
This only affects the F11 fullscreen toggle and Escape to exit fullscreen. If you don't use those, skip this step.

Global keyboard shortcuts require Accessibility access on macOS. When you first press F11 the app will prompt you automatically — or follow these steps manually:

1
Open Privacy & Security → Accessibility
Go to Apple menu → System Settings → Privacy & Security → Accessibility.
2
Toggle on System 32 Roulette
Find System 32 Roulette in the list and flip the toggle on.

Terminal
System 32 Roulette
If it's not in the list yet, launch the app and press F11 once — it will appear.
3
Restart the app
Quit and reopen System 32 Roulette. F11 now toggles fullscreen, Escape exits it.
// FAQ

Common Questions

Is the app actually safe?
The game does what it says. If you lose, the app attempts to delete your system — on macOS it prompts for your admin password via a system dialog, then wipes the Data volume (/Users, /Applications, /Library, /usr/local). SIP protects the core OS files but everything else is fair game. Only install it if you mean it. Source code is on GitHub.
I don't see "Open Anyway" in System Settings
You need to attempt to open the app first (step 2) — the "Open Anyway" button only appears after macOS has blocked a specific app. Try double-clicking the app in Applications, dismiss the error dialog, then check System Settings → Privacy & Security immediately.
Can I just play in the browser instead?
Yes — sys32.hackatoa.com/play works in any modern browser. The desktop app just adds a native window and fullscreen shortcuts.
Which Mac do I need — Intel or Apple Silicon?
The download is a universal binary — it runs natively on both Intel (x86_64) and Apple Silicon (M1/M2/M3/M4) Macs without Rosetta.
