# System 32 Roulette

A competitive 1v1 minigame battler — win rounds, or (jokingly) face system annihilation.

🔗 **Live:** [sys32.hackatoa.com](https://sys32.hackatoa.com)   ·   ☕ **Support:** [Buy Me a Coffee](https://buymeacoffee.com/hackatoa)

## Overview

A tongue-in-cheek minigame battler where two players face off across quick rounds. Includes a shared room where each player sees the game in their own language.

## Features

- 1v1 minigame battles with a shared room
- Landing, `/macos`, and `/play` room
- Per-player localization inside shared rooms
- Global leaderboard

## Tech Stack

HTML · vanilla JS · Node.js · Docker

## Development

```bash
npm install
npm start
```

## Deployment

Docker on the homelab games host; GHCR + Watchtower auto-deploy.
